Account Service

    Responsibilities
        • Create and manage CASA accounts (savings, current)
        • Fixed Deposit lifecycle (open, mature, auto-renew)
        • Wallet management (prepaid, credit)
        • Balance enquiry with real-time locking
        • Account statement generation (async PDF)

    Database: PostgreSQL with row-level locking on balance fields

    API Endpoints
        POST /api/v1/accounts
        GET /api/v1/accounts/{id}/balance
        GET /api/v1/accounts/{id}/statement?from=&to=
        PUT /api/v1/accounts/{id}/status
        POST /api/v1/accounts/fd/open
        POST /api/v1/accounts/fd/{id}/premature-close

    Key Patterns
        • Optimistic locking (@Version) on balance field — prevents double-spend
        • Saga choreography for multi-step account opening
        • Statements: async batch job → MinIO/S3 → pre-signed URL (15-min expiry)
        • No SELECT without FOR UPDATE when modifying balance

    Kafka Events Published : account.created, account.closed, account.balance-updated
